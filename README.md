# LBS 포트폴리오

스타일링, 공연 기획, 실사용 웹사이트, 로고까지 실제 작업물을 큐브 한 칸 한 칸으로 보여 주는 포트폴리오 사이트예요.

## 작업 올리기 · 고치기
1. `사이트주소/#/edit` 로 들어가서 로그인 (콜타임 보드 PD 계정과 같은 이메일 · 비밀번호)
2. 위에 **편집 모드** 바가 생겨요
   - **+ 새 작업**: 작업명 · 클라이언트 · 날짜 · 분야 · 링크 · 설명 · 사진(여러 장)
   - **소개 편집**: 로고 이름, 헤더 한 줄 소개, ABOUT, 연락처, 분야 목록
   - 작업 카드와 상세 페이지의 **편집** 버튼: 고치기 · 사진 순서 · 커버 · 캡션 · 삭제
3. **공개**를 끄면 나만 보이는 초안이에요

사진은 고르는 즉시 긴 변 1800px(+ 640px 썸네일)로 줄여서 올라가요. PNG는 투명 배경을 지키려고 PNG로 남겨요. 아이폰 HEIC는 JPG로 바꿔서 올려 주세요.

## 구조
| 부분 | 쓰는 것 |
|---|---|
| 화면 | `index.html` 한 파일 (빌드 없음) |
| 데이터 · 로그인 · 사진 | Supabase `calltime-board` 프로젝트 안의 `lbs_site` · `lbs_works` 테이블, `lbs` 저장소 (`supabase/schema.sql`) |
| 배포 | GitHub → Vercel 자동 배포 |

## 누가 무엇을 할 수 있나요
| 사람 | 할 수 있는 것 | 막는 곳 |
|---|---|---|
| 링크를 받은 누구나 | 공개된 작업 보기 | Supabase RLS |
| 주인 (`lbs_owner`에 있는 이메일로 로그인) | 전부 · 초안 보기 | `lbs_is_owner()` |

Supabase anon 키는 공개용이라 `index.html`에 들어 있어도 괜찮아요. 쓰기는 DB 규칙이 막아요.

## 수정하고 다시 배포하기
`index.html`을 고쳐서 GitHub에 올리면(commit · push) Vercel이 자동으로 다시 배포해요. 작업 내용은 DB에 있어서 디자인을 바꿔도 그대로 남아요.
